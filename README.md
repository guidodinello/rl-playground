# RL Playground

Archived reinforcement learning learning material. No longer actively maintained.

## Contents

- **`blackjack/`** — a Q-learning agent for Blackjack from the [Gymnasium](https://gymnasium.farama.org/) tutorial.
- **`src/dqn/`** — a Deep Q-Network project built for a course.
- **`src/truco-uruguayo-gymnasium/`** — an early, `setup.py`-era custom Gymnasium environment for Truco Uruguayo. Superseded by [truco-py](https://github.com/guidodinello/truco-py).

`wordle/` and `monopoly/` are empty placeholder directories left over from ideas that were never started.
